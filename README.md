# DC 클리너

디시인사이드 **본인 계정**의 글, 댓글, 방명록을 조건에 맞춰 한꺼번에 지워 주는 개인용 iPhone/iPad 앱입니다.

몇 년 동안 쌓인 글과 댓글을 하나씩 지우기는 어렵습니다. 이 앱은 "2023년 이전 댓글만", "특정 갤러리 글은 빼고"처럼 조건을 정해 두면, 디시가 막지 않는 속도로 천천히 대신 지워 줍니다. 지우기 전에 내용을 기기에 백업해 두고, 남기고 싶은 글은 보호 목록으로 지켜 줍니다.

> **현재 진행 상황: 3단계 / 12단계** — 화면 틀과 디시 통신 모듈(DcClient)까지 완료했습니다. 로그인 화면은 4단계에서 연결되므로, 지금 빌드에서는 아직 로그인 버튼이 동작하지 않습니다. 아래 [개발 로드맵](#개발-로드맵)을 참고하세요.

## 이런 앱입니다

- **네이티브 iOS 앱**: 모든 화면을 React Native 네이티브 컴포넌트로 만들었습니다. 웹앱이나 웹뷰 래퍼가 아니고, 설치하면 브라우저 없이 단독으로 동작합니다.
- **서버가 없습니다**: 앱이 디시인사이드와 직접 통신합니다. 개발자 서버, 프록시, 분석 도구, 광고가 없습니다.
- **내 글만 지웁니다**: 로그인한 계정의 갤로그에 있는 내 글, 댓글, 방명록만 대상으로 합니다. 다른 사람 글을 수집하는 기능은 없습니다.
- **iOS 26 리퀴드 글래스 디자인**: 탭바, 내비게이션 바, 카드, 버튼이 Apple 기본 글래스 스타일을 따릅니다. iOS 26 미만에서는 반투명 블러로 자동 대체됩니다. 다크 모드를 지원하고, 아이콘은 전부 윤곽선 SF Symbols입니다.
- **한국어 전용**: 모든 화면 문구가 한국어입니다.

## 주요 기능

| 기능 | 설명 | 상태 |
|---|---|---|
| 로그인 | 디시 아이디로 로그인합니다. 비밀번호는 iOS 키체인에만 저장하고, 로그인이 풀리면 자동으로 다시 로그인합니다. | 예정 (3단계) |
| 캡챠 처리 | 자동입력 방지 코드가 나오면 직접 입력하거나, 외부 캡챠 서비스(2Captcha 등) API 키로 자동 처리합니다. | 예정 (4단계) |
| 삭제 프리셋 | 대상(글/댓글/방명록), 갤러리(전체/포함/제외, 일반·마이너·미니), 기간, 키워드 조건을 이름을 붙여 저장합니다. | 예정 (5단계) |
| 미리보기 (Dry-run) | 실제로 지우기 전에 삭제될 항목 수와 목록을 보여주고 확인을 받습니다. | 예정 (5단계) |
| 보호 목록 | 지정한 글과 댓글은 어떤 경로로 실행해도 절대 지우지 않습니다. | 예정 (5단계) |
| 삭제 전 백업 | 지우기 직전에 제목, 본문, 작성 시각을 JSON이나 HTML로 기기에 저장합니다. 파일 앱이나 AirDrop으로 내보낼 수 있습니다. | 예정 (6단계) |
| 삭제 엔진 | 한 건씩 지우고 결과를 검증합니다. 중단돼도 이어서 재개하고, 실패한 항목은 다시 시도합니다. | 예정 (6단계) |
| 자동 일시정지 | 연속으로 실패하거나 차단이 의심되면 스스로 멈추고 알림을 보냅니다. | 예정 (6단계) |
| 방명록 삭제 | 내 갤로그에 달린 방명록을 연도별(복수 선택, 범위, N년 이전)로 지웁니다. | 예정 (5~6단계) |
| 백그라운드 / 스케줄 | 앱을 닫아도 iOS가 허락하는 만큼 이어서 처리합니다. 요일과 시간대를 정해 자동 실행할 수 있습니다. | 예정 (7단계) |
| 앱 잠금 | Face ID나 Touch ID로 앱을 잠그고, 삭제 시작 같은 중요한 동작에 재인증을 요구합니다. | 예정 (8단계) |
| 기록 / 통계 | 삭제 이력을 검색하고 CSV/JSON으로 내보냅니다. 갤러리별, 기간별 통계를 차트로 보여줍니다. | 예정 (9단계) |
| 단축어 연동 | `dccleaner://` URL로 프리셋 실행, 일시정지, 상태 조회를 할 수 있습니다. | 예정 (10단계) |
| 위젯 / Live Activity | 홈 화면 위젯과 잠금화면/Dynamic Island에 진행 상황을 표시합니다. | 예정 (11단계) |
| (!) 도움말 | 모든 설정과 주요 버튼 옆의 (!)를 누르면 기능 설명과 주의사항이 나옵니다. | ✅ 완료 |

## 안전 원칙

삭제한 글은 되돌릴 수 없습니다. 그래서 수동 실행, 스케줄, 단축어 등 **모든 실행 경로**에서 아래 순서를 똑같이 지킵니다.

```
확인 → 백업 → 보호 목록 검사 → 삭제 → 응답 검증
```

- **성공은 검증한 뒤에만 기록합니다.** 디시 응답이 성공이고 목록에서도 사라진 것이 확인돼야 "삭제됨"으로 셉니다.
- **디시 구조가 바뀐 것 같으면 즉시 멈춥니다.** 응답이 예상한 형식과 다르면, 잘못 지우는 일이 없도록 작업을 중단하고 안내합니다.
- **매니저 차단 경고는 자동으로 넘기지 않습니다.** 디시가 "지우면 매니저에게 차단된다"고 경고하는 항목(말머리 삭제 제한, 공지글 댓글 등)은 건너뜁니다.

## 알아 두세요

- **느립니다 (의도된 동작입니다).** 디시는 1분에 약 20회 넘게 요청하면 일시적으로 막습니다. 그래서 앱은 1분에 5~7건 정도만 지웁니다. 항목이 1만 개를 넘으면 전부 지우는 데 하루 이상 걸릴 수 있고, 앱이 예상 소요 시간을 보여줍니다.
- **차단 위험이 있습니다.** 보수적인 속도로 요청하지만, 디시가 계정이나 IP를 제한할 가능성이 완전히 없지는 않습니다.
- **iOS 백그라운드 제한이 있습니다.** iOS는 앱이 백그라운드에서 오래 실행되는 것을 허용하지 않습니다. 빨리 끝내려면 앱을 화면에 켜 두는 것이 가장 확실합니다. 사이드로드 설치에서만 쓸 수 있는 "지속 실행 모드"도 있지만 배터리를 많이 씁니다.
- **"내가 남긴 방명록"은 지울 수 없습니다.** 다른 사람 갤로그에 내가 쓴 방명록은 디시가 목록을 제공하지 않아서 찾을 수 없습니다. 내 갤로그에 달린 방명록만 지원합니다.
- **디시가 사이트를 바꾸면 동작이 멈출 수 있습니다.** 공식 API가 아니라 모바일 웹이 쓰는 요청을 그대로 사용하기 때문입니다. 이 경우 앱이 삭제를 멈추고 업데이트가 필요하다고 안내합니다.
- **개인정보는 기기 밖으로 나가지 않습니다.** 백업, 기록, 디버그 로그는 모두 기기에만 저장됩니다. 외부로 나가는 데이터는 자동 캡챠 모드를 켰을 때 캡챠 서비스로 보내는 캡챠 이미지뿐입니다.

## 빠른 빌드 (Windows, Mac 없음)

### A. GitHub Actions로 서명 없는 IPA 만들기 (Apple Developer 계정 불필요)
1. 이 저장소의 **Actions** 탭에서 **iOS unsigned IPA**를 열고 **Run workflow**를 누릅니다. `main`에 push해도 자동으로 실행됩니다.
2. 실행이 끝나면(약 15~25분) 하단 **Artifacts**에서 `DC-Cleaner-unsigned-ipa`를 받아 압축을 풉니다.
3. Windows PC에 **Sideloadly**를 설치하고 iPhone/iPad를 USB로 연결합니다.
4. Sideloadly에 `.ipa`를 끌어다 놓고 본인 Apple ID로 서명해 설치합니다.
5. 기기에서 **설정 > 일반 > VPN 및 기기 관리**로 들어가 개발자를 신뢰합니다. iOS 16 이상이면 **설정 > 개인정보 보호 및 보안 > 개발자 모드**도 켭니다.

> 무료 Apple ID로 서명한 앱은 **7일마다 다시 서명**해야 합니다 (Sideloadly/AltStore 갱신).

### B. EAS Build (Apple Developer 계정이 있을 때)
```powershell
npm install
npx eas-cli@latest login
npx eas-cli@latest build --platform ios --profile preview
```
- `development`: 개발용 빌드 (expo-dev-client)
- `development-simulator`: 시뮬레이터용 (Mac에서만 의미 있음)
- `preview`: 내부 배포(ad hoc). Apple Developer 계정과 기기 UDID 등록이 필요합니다.
- `production`: App Store용 (지속 실행 모드 때문에 심사를 통과하지 못할 수 있음)
